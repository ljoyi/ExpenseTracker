# P0 首页改版记录

## 版本

| 项目 | 内容 |
| --- | --- |
| 版本 | P0 v3.0 |
| 日期 | 2026-09-10 |
| 状态 | 已实现并通过构建与 UI 回归 |

## 首页

- 移除首页右上角和底部原“+记一笔”按钮，统一由底部导航中间的加号记录账单。
- 顶部显示账本周期标签，点击后从底部打开周期选择弹窗。
- 账本封面卡使用本地图片资源作为背景。
- 账本卡左上方显示结余，下方左侧显示收入，右侧显示支出。
- 结余严格使用收入减支出，按月、按年、全部分别显示月结余/年结余/总结余。
- 金额不显示货币符号，所有展示金额统一保留两位小数。
- 点击账本卡切换到统计 Tab，并沿用首页当前周期。
- 账本卡下方按日期生成多张账单卡片并支持滚动。
- 每日卡片左上显示日期，右上显示“收”和“支”，不显示结余。
- 当日收入或支出为 0 时，隐藏对应汇总项。
- 每日明细左侧显示分类，右侧显示带正负号的金额；收入绿色、支出红色。

## 底部导航与标题

- 底部导航从“账单、统计、我的”改为“账单、+、我的”。
- 原统计 Tab 替换为中间的加号入口。
- 点击加号打开“记一笔”，保存后自动返回原页面并刷新账单。
- 统计页面不再由底部导航进入，改为点击账本封面卡后进入。
- 账单、统计、我的页面顶部均不再显示页面名称文字。

## 周期选择

- 移除页面顶部取消按钮，通过下滑或点击背景关闭。
- 显示方式包含“按月、按年、全部”。
- 显示方式使用图标和文字。
- 按月：年份使用可左右滚动的完整年份列表，默认当前年份居中；月份默认当前月，点击月份后立即确认。
- 年份仅显示数字，例如 `2026`，不显示单位或千位分隔符。
- 按年：4×4 最近年份矩阵，当前年份默认选中；点击年份后立即确认。
- 全部：显示说明文字“在首页加载当前账本下所有时间范围内的数据”，点击确认后生效。
- 周期选择页面内的选中高亮统一使用 RGB(79,150,247)。
- 弹窗根据显示方式动态调整高度，避免按月、按年和全部模式出现多余底部空白。
- “全部”模式确认按钮使用同宽的蓝色矩形，并与说明卡片对齐。
- “全部”模式加入账本封面图，使用固定高度保证与该页面其他模式一致。

## 日历

- 从首页右上角日历图标进入独立日历页。
- 月份切换标题使用“<2026年9月>”的紧凑布局。
- 星期标题固定为“周一”到“周日”。
- 每日日期下方显示当天收入与支出数字，收入绿色、支出红色。
- 点击日期后，在日历下方展示当天详细账单卡片。
- 每日使用带阴影的小方框，选中日期使用蓝色阴影高亮。
- 日历下方显示两位小数的月收入、月支出和月结余。

## 未来时间

- 记一笔的日期和时间不再限制为当前时间之前。
- 未来账单会出现在对应未来日期、月份、年份和全部范围中。
- “全部”范围同时覆盖最早账单到最晚未来账单。

## 记一笔与时间选择

- 记一笔使用完整页面呈现，不再从底部弹出。
- 顶部移除“记一笔”标题，改为大尺寸支出/收入切换。
- 顶部关闭按钮和支出/收入切换使用液态玻璃效果。
- 支出选中为红色，收入选中为绿色。
- 分类选项改为圆形图标选中框。
- 分类默认选中当前类型的第一个分类。
- 分类区域隐藏滚动条，并保证常用分类完整显示。
- 取消按钮改为“X”，支持从左边缘右滑返回，退出不再二次确认。
- 键盘调整为四行：
  - `1 2 3 删除`
  - `4 5 6 -`
  - `7 8 9 +`
  - `清除 0 . 保存`
- 加减键支持连续金额计算，保存时计算最终金额。
- 金额和时间的底部面板固定，不随分类数量或分类高度变化。
- 键盘整体使用浅灰色背景。
- 每个数字、运算符、删除、清除和保存按键均使用带阴影的浅白色小方块。
- 金额输入采用逐字符回显：`1`、`12`、`12.`、`12.3`、`12.34`。
- 删除时逐位回退；删除完成后显示 `0`，点击“清除”直接显示 `0`。
- 支出/收入切换使用滑动选中动画。
- 删除“分类”标题，并补偿等量间距，保持第一行分类图标位置不变。
- 日历页保持年月切换与日历卡统一成组，随页面内容整体滚动。
- 账单首页的周期标签移动到导航栏左侧，与右侧日历图标位于同一个固定顶部栏。
- 首页下方从账本卡开始的全部内容独立滚动，周期标签不再随滚动移动。
- 首页顶部使用自定义固定容器，左侧恢复“2026年9月”等周期文字，右侧保留日历图标；进入子页面时恢复系统返回栏。
- 首页顶部改用系统导航栏，周期标签与日历图标分别放入左右工具栏，页面滚动时由系统提供内容穿透、模糊和半透明过渡。
- 周期标签改放在系统导航栏 principal 位置，避免文字被布局吞掉；顶部滚动边缘显式使用 iOS 26 的 `soft` 效果。
- 周期标签移至导航栏左侧并固定尺寸；周期选择由系统 Sheet 改为自定义底部弹层，点击背景立即关闭，动画可被打断。
- 回退系统导航栏、principal 标签和自定义底部弹层实验，恢复为 `VStack` 自定义固定顶部栏与系统底部 Sheet。

## 分类目录

- 支出分类：三餐、零食、衣服、交通、旅行、孩子、宠物、话费网费、烟酒、学习、日用品、住房、美妆、医疗、发红包、汽车/加油、娱乐、请客送礼、电器数码、运动、水电煤、其它。
- 收入分类：工资、生活费、收红包、外快、股票基金、其它。
- 每行固定显示 5 个分类，所有分类完整展示且隐藏滑动轨道。
- 旧版内置分类会在启动时自动迁移到新目录，关联账单不会丢失。
- 时间弹窗首行包含“选择时间、取消、确认”。
- 年月支持双滚轮选择，月份下方使用日期网格选择具体日期。
- 选择日期后自动进入小时和分钟双滚轮。
- 提供今天、昨天、前天以及当前时间快捷入口。
