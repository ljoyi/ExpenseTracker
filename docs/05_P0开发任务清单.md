# P0 开发任务清单

## 1. 使用说明

- 任务按依赖顺序排列，不建议跳过大跨度基础任务直接开发统计。
- 每个任务必须在交付物和验收条件都完成后才能勾选。
- `关键路径` 表示会阻塞后续核心闭环，应优先完成。
- 本清单不包含时间估算；排期应在确认开发投入后再添加。
- 复杂度仅用于拆分和并行安排：`S` 小、`M` 中、`L` 大。

## 2. 里程碑

| 里程碑 | 结果 |
| --- | --- |
| G0 工程基线 | 项目可启动，模型和测试环境可用 |
| G1 记账可用 | 可以新增、保存并持久化一笔账单 |
| G2 账单可用 | 可以按月、按日查看和定位账单 |
| G3 管理闭环 | 可以查看、修改、删除并保持数据一致 |
| G4 统计可用 | 可以查看周期总览、分类占比和分类明细 |
| G5 发布候选 | 状态、边界、性能和验收全部通过 |
