# 四张核心页面线框图与状态

> P0 v1.2 修订：首页不再直接展示月历，已改为账本封面卡、周期标签和按日账单卡片；日历移动到右上角独立页面；记账支持未来时间；金额统一两位小数且不显示货币符号。具体改版口径见 [`06_P0首页改版记录.md`](06_P0首页改版记录.md)。

## 1. 设计基线

| 项目 | 内容 |
| --- | --- |
| 页面数量 | 4 个核心页面 |
| 参考宽度 | 390 pt，iPhone 竖屏 |
| 导航 | 底部“账单、统计、我的” |
| 页面容器 | 使用系统安全区，底部主要操作不遮挡内容 |
| 图标 | SF Symbols |
| 字体 | 系统字体，跟随动态字体设置 |
| 颜色 | 收入绿色、支出红色，同时使用 `+/-` 和文字辅助表达 |
| P0 原则 | 页面只暴露冻结范围，不展示不可用功能入口 |

四个核心页面：

1. 账单页
2. 记一笔页
3. 账单详情页
4. 统计页

“我的”页在 P0 只作为导航占位，不纳入核心线框和交互验收。

## 2. 页面关系

```text
账单页
  ├─ 点击 + -> 记一笔页（新增）
  ├─ 点击账单条目 -> 账单详情页
  │                    └─ 点击修改 -> 记一笔页（编辑）
  └─ 切换底部导航 -> 统计页 / 我的

统计页
  └─ 点击分类 -> 分类账单列表

记一笔页
  ├─ 保存成功 -> 返回账单页或详情页
  ├─ 未保存退出 -> 返回行为确认
  └─ 保存失败 -> 留在当前页并提示
```

## 3. 账单页

### 3.1 页面目标

在一个页面中回答三个问题：

- 当前月份收入、支出和结余是多少？
- 哪一天发生过账单？
- 选中日期具体有哪些账单？

布局规则：

- 月份是页面唯一时间上下文，概要和列表必须与它一致。
- 日历仅标记是否存在账单，不直接展示金额。
- 日历默认选中当天；若当天不在当前月份，则默认选中该月 1 日。
- 下方列表默认只展示选中日期的账单。
- “今天”按钮用于快速返回当前月和今天。
- “+”按钮固定可见，不随列表滚动消失。

### 3.5 交互规则

- 点击月份左右按钮，每次切换一个月。
- 点击当前年月标题可打开年月选择器，年份按连续滚动或列表选择，月份平铺 1-12。
- 点击日期：高亮该日期，并刷新下方账单列表。
- 点击日历有账单标记的日期：行为与普通日期一致，不直接跳转。
- 点击账单条目：打开详情。
- 点击“+”：打开新增记账页。
- P0 不提供列表搜索、按金额排序和批量操作。

### 4.4 页面规则

- 默认类型为支出。
- 默认时间为当前时间。
- 分类默认无选中状态。
- 金额、类型和分类是必填项。
- 保存按钮只有在金额大于 0 且已选择正确分类时可用。
- 编辑模式下预填原账单，全部规则与新增一致。
- P0 不提供备注、图片、账户、账本、退款、不计入统计等字段。

### 4.6 金额键盘规则

- 首次输入数字时替换 `0.00` 占位。
- 输入 `.` 时自动显示 `0.`。
- 最多保留两位小数。
- 前导零自动规范化。
- 删除键删一个字符；删除为空时回到 `¥0.00`。
- 不提供加减号，收支方向由类型切换决定。
- 保存时转换为“分”的整数，禁止字符串直接参与统计。

- 修改保存成功后回到详情页并更新详情内容。
- P0 详情不展示备注、账户、账本、图片和来源。

| 加载 | 使用局部骨架或进度指示，禁止长时间全屏白屏 |
| 空数据 | 说明“为什么为空”和“下一步怎么做” |
| 表单错误 | 错误紧邻对应字段，不使用只有颜色没有文字的提示 |
| 保存中 | 按钮禁用并显示进度，防止重复提交 |
| 保存成功 | 轻微成功反馈后自动返回来源页 |
| 保存失败 | 保留输入、说明原因、提供重试 |
| 删除确认 | 展示金额、分类和时间，避免误删 |
| 致命错误 | 不显示零值冒充正常数据，明确提供重试或返回 |
| 动态字体 | 大字号下允许换行和纵向扩展，不截断金额 |
| 深色模式 | P0 可使用系统自动适配；图表和颜色必须保持可读 |

## 8. 页面跳转与返回规则

| 起点 | 操作 | 目标 | 返回行为 |
| --- | --- | --- | --- |
| 账单页 | 点击 + | 记一笔页 | 取消返回账单页 |
| 账单页 | 点击条目 | 账单详情页 | 返回原月份和原选中日期 |
| 账单详情页 | 点击修改 | 记一笔页 | 取消返回详情，保存返回详情 |
| 记一笔页 | 保存成功且来自新增 | 账单页 | 定位到该账单日期并刷新 |
| 记一笔页 | 保存成功且来自编辑 | 账单详情页 | 显示更新后的数据 |
| 统计页 | 点击分类 | 分类下钻列表 | 返回原周期、原类型和滚动位置 |

## 9. P0 线框验收

- [ ] 四张核心页面均具备正常、空、错误和操作中状态。
- [ ] 页面没有超出 P0 范围的可见入口。
- [ ] 所有红绿金额同时有正负号或文字说明。
- [ ] 月度概要、日历、列表和统计使用同一数据口径。
- [ ] 所有保存、删除和失败场景都能回到可继续操作的状态。
- [ ] 页面在 390 pt 宽度和较大动态字体下不出现关键内容重叠。
